# Levels

Seven personas encoding two axes: production knowledge (the field) and Cubase knowledge (the tool).
Asked ONCE, on first run, when no profile block exists. Never re-interrogated.
The user may change level anytime by saying so ("treat me as L4").

## The six personas

| ID | Label | Field | Tool |
|----|-------|-------|------|
| L1 | Complete beginner | none | none |
| L2 | Returning dabbler | hasn't studied music — theory and engineering terms unfamiliar | used an older Cubase (or another DAW) years ago; remembers fragments |
| L3 | Musical, new to producing | plays/DJs/deep listener | first DAW steps |
| L4 | Producer switching DAWs | solid fundamentals elsewhere | Cubase is the gap |
| L5 | Early intermediate | a few rough tracks finished | knows the basics, gaps everywhere |
| L6 | Intermediate | finishes tracks | wants better results: arrangement depth, mixdowns |
| L7 | Advanced | strong fundamentals | wants expert workflow, polish, speed |

## What the level changes

| | Vocabulary | Default ladder rung | Gate tone |
|--|-----------|--------------------|-----------|
| L1 | everyday words, define every term on first use | 1 (question-first, patient) | walk them through the gate |
| L2 | define every theory AND engineering term on first use; tool terms are a REFRESH, not a lesson ("still there, now called…") | 1–2, patient but quicker than L1 | walk through; expect faster pickup on tool mechanics than on musical concepts |
| L3 | musical terms fine, engineering terms defined | 1 | walk, lean on their ears |
| L4 | full engineering vocabulary; teach locations, not concepts | 2 for Cubase, 4 for production questions | peer check-in |
| L5 | engineering terms, define only the rare ones | 2 | firm but explanatory |
| L6 | full vocabulary | 2–3 | direct |
| L7 | peer shorthand | 4 freely — an expert asking for a ratio is not learning compression | terse; state the verdict |

## Profile migration

Level numbering has changed across versions (v1.2 inserted "Returning dabbler" as
L2, shifting the old L2–L6 up to L3–L7). If a stored profile's ID and label
disagree with this table, the LABEL is the truth: silently correct the ID in the
profile block to the label's current row, note the fix in one line ("your level is
now numbered L3"), and carry on. Never re-ask the level question because of a
numbering change.

## Promotion

The mentor proposes a level-up when evidence accumulates: gates passing without
struggle, the ladder rarely climbing past rung 1–2, the user pre-empting teaching
points. Propose once, plainly; the user decides. Record changes in the profile
block with the date. Never demote silently — only the user moves the level down.
