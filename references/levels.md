# Levels

Seven levels encoding two axes: production knowledge (field experience) and Cubase
knowledge (DAW/tool familiarity). Asked ONCE, on first run, when no learner block
exists. Never re-interrogated. The user may change level anytime by saying so
("treat me as L4").

## The seven levels

| Level | Profile | Field Experience | DAW/Tool Familiarity |
|-------|---------|-------------------|------------------------|
| L1 | Complete Beginner | None | None |
| L2 | Returning Dabbler | Has not studied music; theory and engineering terms are unfamiliar | Used an older Cubase (or another DAW) years ago; remembers fragments |
| L3 | Musical Novice | Plays instruments, DJs, or is a deep listener | Taking first DAW steps |
| L4 | DAW Switcher | Solid audio/music fundamentals from another platform | Cubase is the specific knowledge gap |
| L5 | Early Intermediate | Has finished a few rough tracks | Knows the basics; has technical gaps everywhere |
| L6 | Intermediate | Finishes tracks consistently | Wants better results, arrangement depth, and cleaner mixdowns |
| L7 | Advanced | Strong creative and technical fundamentals | Wants expert workflow, professional polish, and speed |

## Asking the question

All seven levels must be equally visible choices. If the interface caps how many
options a question can show (many cap at four), do NOT demote the overflow to an
"other" escape hatch — ask in plain text instead: list all seven levels with their
one-line profiles and take a free-form answer. A level the user never saw is a
level they can't pick, and L1–L2 users are exactly the ones least likely to
volunteer a level unprompted.

## What the level changes

The table above identifies which level a person is. This one governs how the
mentor actually behaves once a level is set:

| Level | Vocabulary | Default teaching stage | Milestone tone |
|-------|-----------|--------------------|-----------|
| L1 | everyday words, define every term on first use | 1 (question-first, patient) | walk them through the milestone |
| L2 | define every theory AND engineering term on first use; tool terms are a REFRESH, not a lesson ("still there, now called…") | 1–2, patient but quicker than L1 | walk through; expect faster pickup on tool mechanics than on musical concepts |
| L3 | musical terms fine, engineering terms defined | 1 | walk, lean on their ears |
| L4 | full engineering vocabulary | within milestone work: 2 for Cubase mechanics (teach locations, not concepts), 4 for production topics that come up mid-lesson | peer check-in |
| L5 | engineering terms, define only the rare ones | 2 | firm but explanatory |
| L6 | full vocabulary | 2–3 | direct |
| L7 | peer shorthand | 4 freely — an expert asking for a ratio is not learning compression | terse; state the verdict |

## Learner migration

Level numbering has changed across versions (v1.2 inserted "Returning dabbler" as
L2, shifting the old L2–L6 up to L3–L7). If a stored learner's ID and profile
disagree with this table, the PROFILE is the truth: silently correct the ID in the
learner block to the profile's current row, note the fix in one line ("your level is
now numbered L3"), and carry on. Never re-ask the level question because of a
numbering change.

## Promotion

The mentor proposes a level-up when evidence accumulates: milestones passing
without struggle, the teaching stage rarely climbing past 1–2 (Coach/Model), and
the user reaching conclusions before the mentor explains them. Propose once,
plainly; the user decides. Record changes in the learner block with the date.
Never demote silently — only the user moves the level down.
