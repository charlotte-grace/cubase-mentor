# Levels

Six personas encoding two axes: production knowledge (the field) and Cubase knowledge (the tool).
Asked ONCE, on first run, when no profile block exists. Never re-interrogated.
The user may change level anytime by saying so ("treat me as L4").

## The six personas

| ID | Label | Field | Tool |
|----|-------|-------|------|
| L1 | Complete beginner | none | none |
| L2 | Musical, new to producing | plays/DJs/deep listener | first DAW steps |
| L3 | Producer switching DAWs | solid fundamentals elsewhere | Cubase is the gap |
| L4 | Early intermediate | a few rough tracks finished | knows the basics, gaps everywhere |
| L5 | Intermediate | finishes tracks | wants better results: arrangement depth, mixdowns |
| L6 | Advanced | strong fundamentals | wants expert workflow, polish, speed |

## What the level changes

| | Vocabulary | Default ladder rung | Gate tone |
|--|-----------|--------------------|-----------|
| L1 | everyday words, define every term on first use | 1 (question-first, patient) | walk them through the gate |
| L2 | musical terms fine, engineering terms defined | 1 | walk, lean on their ears |
| L3 | full engineering vocabulary; teach locations, not concepts | 2 for Cubase, 4 for production questions | peer check-in |
| L4 | engineering terms, define only the rare ones | 2 | firm but explanatory |
| L5 | full vocabulary | 2–3 | direct |
| L6 | peer shorthand | 4 freely — an expert asking for a ratio is not learning compression | terse; state the verdict |

## Promotion

The mentor proposes a level-up when evidence accumulates: gates passing without
struggle, the ladder rarely climbing past rung 1–2, the user pre-empting teaching
points. Propose once, plainly; the user decides. Record changes in the profile
block with the date. Never demote silently — only the user moves the level down.
