# Structure and Loops

## Think in layers

A track is independently muteable layers, not one blob:
- **base** — rhythm/pulse; the thing that keeps time
- **harmony** — chords/pads; the emotional floor
- **melody** — the element a listener would hum
- **tension** — risers, noise, dissonance; the promise that something changes
Mute any one and the track should still make sense. Building in layers is what makes
M2 arrangement possible: sections are layer combinations, not new material.

## From loop to arrangement (M1 → M2)

The 8-bar loop is the track's DNA — it should already contain base + at least one
other layer, and survive looped listening. Arrangement is then energy management:
sections = adding/removing layers; transitions = tension layer + a change at the bar.
Sketch the energy arc first (where is the peak? where does it breathe?), then place
sections to serve it. Contrast is the tool: a drop only lands after a gap; loud only
reads after quiet.

## Loop craft

- Start and end on exact bar boundaries.
- Cut at zero crossings or add a 5–10 ms crossfade — clicks are edits, not character.
- Reverb/delay tails must not spill past the loop end; either tuck the tail inside
  or render the loop with its tail into the next repeat.
- Intro + loop beats a cold start when the material needs a run-up.

## Export discipline

- Masters/stems: WAV, 48 kHz, 24-bit.
- Preview/share bounces: anything convenient; the format matters at M4, not M1.
- Name exports so future-you knows: `<track>-<milestone>-<date>` (e.g. `dusk-M2-2026-08-10`).
- Stems, when needed, follow the layers: one file per layer, all starting at bar 1,
  same length — alignment is the entire point of stems.
